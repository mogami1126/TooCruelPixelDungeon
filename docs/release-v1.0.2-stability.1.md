# 英烈的像素地牢 v1.0.2 稳定修复版 1

基于 TooCruelPixelDungeon 原版 v1.0.2（d3f7188），不是 Shattered 4.0.2 MMO 项目。

## 相对原版的变化

| 部分 | 本版变化 |
|---|---|
| 矮人王 | 护盾与召唤波次按 MMO 放大后的生命计算；处理不能整除时的残盾；修复第三阶段/零血旧档的死亡结算，恢复王冠掉落、解封和下楼；防止重复死亡结算。 |
| 天狗 | 修复快速动画、跳跃被打断时的永久等待；统一逻辑位置与精灵位置，修复初始贴图偏移。 |
| 卡住恢复 | 对确认存在的移动动画等待提供超时恢复和菜单恢复入口；不跳过攻击结算。 |
| 回合调度 | 使用定点时间保存回合先后，读取旧浮点存档；连续32次不推进时间的角色被推迟处理，循环周期性让出CPU；旧档长绝对时间不再被误截成单次延迟上限。 |
| 戒指成长 | 使用科学计数式中间运算，避免极高强化的指数计算直接溢出；读档直接恢复等级，减少逐级重放。极速/狂怒保留早期增长，极高等级平滑趋近64倍；正耗时限制在1/64至64回合。 |
| 法杖充能 | 充能按容量限制，极高额外充能直接结算，避免超大循环或无限充能卡住。 |
| 生命与治疗 | 修复根骨戒指、体质灵药、升级和药水等中间计算溢出；食物、圣杯、睡眠、天赋、阳春草及部分召唤物/法杖回血改用安全加法。超过现有int范围时限制为2147483647。 |
| 护盾 | 增长与多层求和饱和处理，英雄生命加护盾的中间统计使用更宽类型，避免变为负数。 |
| 中文 | 按实际机制校对93项挑战/修改器、挑战选择界面和精英说明；补齐自动选择挑战提醒。保留原有玩法和挑战集合。 |
| 界面与图标 | 极长血量在存档预览和角色属性页独占整行，避免截字；本次构建使用原版彩色大嘴宝箱图标，不再被debug灰宝箱覆盖。 |
| 开局与测试入口 | 移除原debug构建的开局赠品及开发期间的不死、直达Boss、测试物资等入口；不向APK加入本轮设备测试脚本。已有测试存档物资不会自动清除。 |
| 验证资料 | 增加Boss、血量、数值、调度回归脚本和模拟器验收记录。 |

## 已验证与边界

- 普通装备天狗/矮人王的预置入口战斗完成并成功下楼；MMO模式也完成两种Boss全部阶段、死亡与下楼。
- 实际饮药/吃馅饼的高血量边界、长血量页面显示、法杖耗尽和卷轴充能有真实模拟器截图。
- 579覆盖安装580后，启动前15份存档和偏好文件逐字节相同；原普通存档保留。
- 四组代码回归及Android构建通过。预置入口测试不等于自然培养通关或完整装备平衡验收。
- 未完成全部挑战组合、完整HP/伤害大数迁移及极端速度全部真实组合验收；任意act()内部死循环不能由返回后保护安全中断。本版没有实现无限生命/无限伤害，也不自动修复历史损坏的负血存档。
