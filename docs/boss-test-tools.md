# 调试版Boss测试

标题画面和游戏菜单的“Boss测试 / 不死”可开启不死、切换快速动画、直达天狗或矮人国王。入口只在INDEV调试版生效。

“直达”生成一个新的战士测试角色，启用Korean MMO及递归前置修改器，额外发放100000张升级卷轴；与原调试开局的100张合并后为100100张。角色放在Boss附近供手动战斗，不会自动攻击。升级卷轴不等于自动强化装备；MMO数值仍为原版。

优先复用标记为测试的存档槽，否则使用空槽。不会覆盖普通存档；每次进入直达或自动测试会重建测试槽。普通存档仍建议不要开启不死测试。

自动验证通过正常攻击动画和实际伤害、召唤、KingDamager和Boss死亡方法运行，额外提供命中和伤害以缩短战斗。通过后自动进入下一层并停止。满场国王测试还启用加强Boss和生成修改器，并用静止中立怪物堵住空格，验证真实召唤失败流程；下层前移除堵位怪和生成压力修改器。

自动验证会快速推进战斗和换层。天狗第二阶段入口需要专门把测试角色移进竞技场，否则跳过正常行走会使视野与战场分离，出现黑屏仍跳伤害。工具已增加该位置修正、视野重算和入口日志；换层成功日志须等待角色恢复可操作状态。

不死只是测试辅助，不修复伤害、血量、速度戒指、治疗溢出等原版数值问题。自动验证不能代替正常装备、手动移动和其他修改器组合的验收。
